# 空间分析课程复习笔记 - 第4讲 空间模式分析

本笔记基于《Lect.4 Spatial Pattern Analysis-2026.pdf》课件整理，严格遵循课件的语言表述。

## 一、 空间模式分析的概念 (The Concept of Spatial Pattern Analysis)

1. **空间模式 (Spatial Pattern / Spatial distribution pattern)**
   * **概念**：空间模式一般是指人或者物体在现实世界中的组织和位置。可以指它们之间的距离的远近或者说它们之间的呈现的相对或者绝对位置的规律。 (史舟)
   * 英文定义：Spatial pattern refers to the organized or structured arrangement of elements in space, which emerges from the interactions and feedback mechanisms within a system.（空间模式是指空间中元素的有组织或结构化的排列，它是系统内相互作用和反馈机制产生的。）
2. **空间模式分析 (Spatial Pattern Analysis)**
   * **作用**：空间模式分析提供了关于事物发生在哪里、事件分布或数据排列如何与景观中其他特征对齐的见解，以及这些模式可能揭示的潜在联系和相关性。 (provides insights about where things occur, how the distribution of incidents or the arrangement of data aligns with other features in the landscape...)
   * **内容**：它涉及识别、描述和测量地理数据中的形状 (shape)、排列 (arrangement)、位置 (location)、配置 (configuration)、趋势 (trend) 或关系 (relationships)。
   * **两个核心概念**：**空间对象 (spatial object)** 与 **分布区域 (distribution area)**。后者是指空间对象占据的空间域。
   * 空间对象有点、线、多边形类型；分布区域有线和多边形类型；空间分布有离散和连续类型。

## 二、 空间分布/模式的类型 (Spatial Distribution/Pattern Types)

它包括 7 种基本的空间分布/模式类型：
1. **沿线特征的离散点 (Discrete points along line features)**：例如沿道路或河流的车站或码头。
2. **沿线特征的连续分布 (Continuous distribution along line features)**：例如河流的流速或径流。
3. **多边形特征中的离散点 (Discrete points in polygon features)**：例如某区域内的城市分布。
4. **线性分布 (Linear distribution)**：例如交通网络。
5. **多边形的离散分布 (Discrete distribution of polygon)**：例如农田分布。
6. **多边形的连续分布 (Continuous distribution of polygon)**：例如行政区域。
7. **空间连续分布 (Spatially continuous distribution)**：例如降水分布。

*课件案例指出，近五年关于空间模式的文献检索中，**点模式 (Point)** 占据主导地位 (约95%)，其次是面模式 (Area, 4%) 和线模式 (Line, 1%)。*

## 三、 点模式的分析方法 (The Analysis Methods of Point Patterns)

点模式的三种基本类型：**离散 (Dispersed)**、**随机 (Random)**、**聚集 (Clustered)**。

### 1. 样方分析 (Quadrat Analysis)

* **基本步骤**：
  1. 在研究区域画一个矩形（如 6×5 厘米）；
  2. 随机放置点（如 30 个点）；
  3. 在矩形顶部画出等大小的网格单元（如 6×5=30 个正方形单元）；
  4. 给结果打分（每个单元格包含的点数不同，得分不同）；
  5. 将所有单元格的分数相加得出总分。对于完全随机的点集，大多数分数会聚集在一个特定范围内。
* **方差-均值比方法总结 (Summary of the quadrat method)**：
  1. 将研究区域划分为 $m$ 个大小相等的单元格 (cells)。
  2. 找出每个单元格点的平均数量 ($\bar{x}$)。等于总点数除以单元格数 $m$。
  3. 计算每个单元格点数的**方差 ($s^2$)**：$s^2 = \sum_{i=1}^m(x_i - \bar{x})^2 / (m-1)$
  4. **计算方差-均值比 (Variance-Mean Ratio, VMR)**：$VMR = s^2 / \bar{x}$
* **结果解释 (Interpret the results)**：
  * **$VMR < 1$**：方差小于均值。极端情况下各单元格点数变化极小，这种模式表现为**离散 (spread out, or uniform/dispersed)**。
  * **$VMR > 1$**：方差大于均值，有的单元格点数远多于预期，有的远少于预期。这种模式表现为比随机更**聚集 (clustered)**。
  * **$VMR \approx 1$** (接近1)：表明点在研究区域内接近**随机分布 (randomly distributed)**。
* **假设检验 (Hypothesis Testing)**：
  * 当自由度较小时，计算卡方统计量 $\chi^2 = (m-1)VMR$。
  * 当自由度 $df > 30$ 时，抽样分布接近正态分布，可视为均值0、方差1的标准正态变量进行Z检验：$z = \frac{(m-1)VMR - (m-1)}{\sqrt{2(m-1)}} = \sqrt{(m-1)/2} \cdot (VMR - 1)$。
  * 将统计值与无模式零假设下的临界值进行比较，决定接受或拒绝零假设（如当 $\alpha = 0.05$ 时，若 $z < -1.96$ 为均匀/离散；$z > 1.96$ 为聚集）。
* **空间尺度的重要性**：样方分析的结果对样方大小高度敏感。单元格太小会有许多空单元，掩盖除最小空间尺度外的所有聚类；单元格太大可能会掩盖单元格内发生的模式。
* **【优缺点 (Advantages and Disadvantages)】**
  * **优点 (Advantages)**：
    1. **简单直观**：样方分析的计算方法简单，结果易于理解和解释，适合快速评估点数据的空间分布模式。
    2. **适用于离散数据**：样方分析直接基于点的数量，适合处理离散数据（如事件点、设施点）。
    3. **无需复杂参数设置**：只需要设置样方的大小和形状，不需要像核密度估计那样选择带宽或核函数。
    4. **易于与其他空间分析结合**：样方分析的结果通常以栅格形式输出，便于与其他栅格数据（如土地利用、地形）进行叠加分析。
    5. **适用于大范围数据**：可以处理大范围的点数据，适合区域尺度的空间分布研究。
    6. **统计检验方便**：可以通过卡方检验 (Chi-square test) 等方法，检验点数据是否偏离完全随机分布 (CSR)。
  * **缺点 (Disadvantages)**：
    1. **样方大小依赖性**：结果高度依赖于样方大小的选择。样方过大可能导致细节丢失，样方过小可能导致统计结果不稳定。
    2. **边界效应**：在样方边界附近，点可能被分配到相邻样方，导致统计结果不准确。
    3. **不适用于小样本数据**：当点数据较少时，样方分析的结果可能不够稳定，容易出现零值或极端值。
    4. **无法处理权重数据**：标准的样方分析无法直接处理带权重的点数据（如不同点的重要性不同），需要额外处理。
    5. **形状限制**：样方通常为规则形状（如正方形或矩形），可能无法适应不规则研究区域的需求。

### 2. 点密度分析 (Point Density)

* **基本原理 (Basic idea)**：
  * 计算每个输出栅格单元周围的点要素密度。在概念上，围绕每个栅格单元中心定义一个邻域 (neighborhood，如圆形)，统计落入该邻域内的点数并除以邻域的面积。
  * 【公式】：$P(s) = \frac{\# s \in C(s,r)}{\pi r^2}$  （其中 $P(s)$ 为点 $s$ 的点密度，$C(s,r)$ 表示以 $s$ 为中心、$r$ 为半径的圆，$\# s$ 是落入圆 $c$ 中的事件数）。
* **半径 (Radius) 的影响**：
  * 增大半径不会极大地改变计算出的密度值。虽然会有更多的点落入更大的邻域，但在计算密度时该数字也会除以更大的面积。
  * 较大半径的主要影响是：密度是考虑了更大数量的点来计算的，这些点可能离栅格单元较远。
  * 这将产生一个更加**概括 (generalized)** 的输出栅格。在某种程度上，半径可以被视为空间尺度 (spatial scale)。
* **填充/人口字段 (Population Field)**：
  * 如果使用了 Population 字段，该字段的值决定了点被计算的次数（如值=3的点将被算作三个点）。值可以是整数或浮点数。
  * 可能的用途包括查找房屋密度、野生动物观测值或犯罪报告。它可以用于使某些点比较其他点具有更大的权重，或允许一个点代表多个观测值。
* **主要缺点**：点密度方法的主要缺点是，密度存在从一个值突然变化到另一个值的可能性 (the possibility of a sudden change in density from one value to another)。
* **【优缺点 (Advantages and Disadvantages)】**
  * **优点 (Advantages)**：
    1. **简单直观**：计算方法简单，结果易于理解和解释，适合快速了解点数据的空间分布特征。
    2. **计算效率高**：由于算法简单，计算速度快，适合处理大规模数据集。
    3. **无需复杂参数设置**：只需要设置网格大小（分辨率），不需要像核密度估计那样选择带宽或核函数。
    4. **适用于离散数据**：直接基于点的数量，适合处理离散数据（如事件点、设施点）。
    5. **易于与其他空间分析结合**：结果通常以栅格形式输出，便于与其他栅格数据（如土地利用、地形）进行叠加分析。
    6. **边界清晰**：由于使用规则网格，点密度分析的结果边界清晰，适合需要明确空间单元的应用场景。
  * **缺点 (Disadvantages)**：
    1. **平滑性不足**：结果通常是离散的栅格数据，缺乏核密度估计的平滑性，可能无法反映数据的连续分布特征。
    2. **分辨率依赖性强**：结果高度依赖于网格大小的选择。网格过大可能导致细节丢失，网格过小可能导致密度分布过于分散。
    3. **边界效应**：在网格边界附近，点密度分析可能不准确，尤其是当点位于网格边缘时。
    4. **不适用于小样本数据**：当点数据较少时，分析结果可能不够稳定，容易出现零值或极端值。

### 3. 核密度分析 (Kernel Density)

* **基本原理 (Basic idea)**：
  * 使用核函数 (kernel function) 为每个点或折线要素拟合出一个平滑变细的表面 (smoothly tapered surface)，计算单位面积的量级。可用于点和线要素。
  * 核密度类似于点密度，但它使用核函数来塑造输出。
  * 【公式】：$f(s) = \frac{1}{n} \sum_{i=1}^n K_\tau(s - s_i) = \frac{1}{n\tau} \sum_{i=1}^n K\left(\frac{s-s_i}{\tau}\right)$ 
  （其中 $K_\tau(s)$ 代表核函数 kernel function，$\tau$ 代表带宽 band width）。
* **核函数 (Kernel function)**：
  * 核函数是非负的，积分值为 1，均值为 0。
  * 常用的核函数包括：均匀核 (Uniform)、三角核 (Triangular)、Epanechnikov核、二权核 (Biweight) 等。ArcGIS 预测密度即基于核函数公式。
* **算法细节**：
  * 在概念上，一个平滑弯曲的表面覆盖在每个点上。表面值在点位置最高，随着距离增加而减小，在搜索半径 (Search radius) 处达到零。
  * 仅可能使用圆形邻域。输出栅格单元处的密度是通过将在该栅格单元中心重叠的所有核表面值相加计算得出的。
* **搜索半径/带宽 (Bandwidth)**：
  * 确定默认搜索半径（即带宽）的算法为：先计算输入点的平均中心，计算距平均中心的加权距离中位数 $D_m$ 和标准距离 $SD$。
  * 最后应用公式：$SearchRadius = 0.9 \times \min\left(SD, \sqrt{\frac{1}{\ln(2)}} \times D_m\right) \times n^{-0.2}$。
* **障碍物 (Barrier) 对计算的影响**：例如洛杉矶深夜交通事故的核密度估计，如果没有障碍物，密度会跨街区平滑计算；如果将道路两侧设为障碍物，密度计算将被限制在道路网络结构内部。
* **【优缺点 (Advantages and Disadvantages)】**
  * **优点 (Advantages)**：
    1. **直观可视化**：核密度估计能够生成平滑的密度表面，直观地展示点数据的空间分布特征，便于理解和解释。
    2. **无需假设分布形式**：作为一种非参数方法，核密度估计不依赖于数据的具体分布形式，适用于各种复杂的数据分布。
    3. **灵活性强**：通过调整核函数类型（如高斯核、Epanechnikov核）和带宽（bandwidth），可以灵活地控制密度估计的平滑程度。
    4. **适用于多尺度分析**：核密度估计可以揭示数据在不同空间尺度下的分布特征，适用于多尺度分析。
    5. **广泛应用**：适用于多种领域，如生态学（物种分布）、犯罪学（犯罪热点分析）、城市规划（人口密度分析）等。
  * **缺点 (Disadvantages)**：
    1. **带宽选择敏感**：核密度估计的结果对带宽的选择非常敏感。带宽过小会导致密度表面过于粗糙，带宽过大会导致过度平滑，掩盖细节特征。
    2. **计算复杂度高**：对于大规模数据集，核密度估计的计算量较大，尤其是在高维数据或多维空间分析中。
    3. **边界效应**：在数据边界附近，核密度估计可能不准确，因为核函数会超出边界范围，导致密度低估。
    4. **对异常值敏感**：核密度估计对异常值较为敏感，异常值可能会显著影响密度表面的形状。

### 4. 平均最近邻分析 (Average Nearest Neighbor)

* **基本原理**：这是一种将**观察到的点与其最近邻点之间的平均距离**与**在随机模式下预期的最近邻距离**进行比较的方法。由 Clark 和 Evans 在 1954 年开发，最初用于分析植物物种的空间分布。
* **【最近邻统计量 (Nearest neighbor statistic)】**：
  * $R = \frac{R_0}{R_e} = \frac{\bar{x}}{1/2\sqrt{\lambda}} = \frac{\bar{x}}{1/2\sqrt{n/A}} = 2\bar{x} \sqrt{n/A}$
  * 其中 $R_0$ 或 $\bar{x}$ 为观察到的点与其最近邻点之间的平均距离；$R_e$ 为点随机分布时的预期距离；$\lambda$ 为单位面积的点数（点密度）；$n$ 为点数；$A$ 为研究区域面积。
* **结果解释**：
  * 统计上，$R$ 从 $0$（所有点位于同一位置，最近邻距离为 0）变化到理论最大值约 $2.14$（在无限大的二维平面上完美的均匀或系统散布模式）。
  * **$R = 1$ 表示随机模式 (random pattern)**，因为观察到的最近邻平均距离等于随机模式中的预期距离。
* **假设检验 (z-score)**：
  * $z = \frac{(R-1)}{\sqrt{V[R]}} \approx 1.913(R - 1)\sqrt{n}$。量 $z$ 服从均值为 0，方差为 1 的正态分布。
* **【主要问题 (The Main Problem)】**：
  * **该方法对研究区域极其敏感 (very sensitive to the study area)**。Area (面积) 参数值的微小变化可能导致 z 得分和 p 值的显著变化。
  * 因此，Average Nearest Neighbor 工具最有效的情况是用于在固定（同一）研究区域内比较不同的要素分布。如果相同的要素分布由于指定的学习区域面积不同，可能会被判定为离散或聚集。
* **【优缺点 (Advantages and Disadvantages)】**
  * **优点 (Advantages)**：
    1. **简单易用**：平均最近邻分析的计算方法简单，结果易于理解和解释，适合快速评估点数据的空间分布模式。
    2. **直观的统计指标**：通过计算最近邻比率（Nearest Neighbor Ratio, R值），可以直接判断点模式是聚集、随机还是均匀分布。
    3. **适用于小样本数据**：平均最近邻分析对数据量的要求较低，即使点数据较少，也能提供有意义的结果。
    4. **无需复杂参数设置**：该方法不需要像核密度估计那样选择带宽或核函数，使用方便。
    5. **广泛应用于多个领域**：适用于生态学（物种分布）、地理学（设施分布）、犯罪学（犯罪热点分析）等领域。
  * **缺点 (Disadvantages)**：
    1. **对研究区的选择敏感**。 (参考前述 The Main Problem)
    2. **仅考虑最近邻点**：平均最近邻分析只考虑每个点的最近邻点，忽略了更远的点及其空间关系，可能导致对整体分布模式的误判。
    3. **对边界效应敏感**：在研究区域边界附近的点，其最近邻点可能位于区域外，导致计算结果不准确。需要采用边界校正方法来减少误差。
    4. **无法反映多尺度特征**：平均最近邻分析只关注最近邻距离，无法揭示点数据在不同空间尺度下的分布特征。
    5. **不适用于复杂点模式**：对于具有复杂空间结构的点模式（如多尺度聚集或混合分布），平均最近邻分析可能无法提供全面的描述。
    6. **结果解释依赖背景知识**：平均最近邻分析的结果需要结合研究区域的背景知识进行解释，否则可能导致误解。

### 5. Ripley's K 函数 (Ripley's K Function)

* **基本原理 (Basic idea)**：
  * 在每个点（事件 $i$）周围构造一个半径为 $d$ 的圆。
  * 计算落在该圆内的其他点（标记为 $j$）的数量。
  * 对所有点 $i$ 重复这前两个阶段，求和结果，然后计算平均值。
  * 将平均值除以点密度 $\lambda$。
  * 以一个小而固定的增量（例如 $d/100$）增加 $d$，不断重复上述计算，从而给出针对一组距离 $d$ 的 $K(d)$ 值。
  * 【公式】：$K(d) = \frac{\sum_i\sum_j k_{i,j}}{\lambda n} = \frac{A}{n^2} \sum_i\sum_j k_{i,j}$
* **结果解释 (The function K(d) can then be plotted against distance, d)**：
  * 在完全空间随机性 (CSR) 下，$K_{CSR}(d) = \pi d^2$。此时点在尺度 $d$ 下呈现随机分布。
  * 如果 $K(d) < \pi d^2$，点在尺度 $d$ 下呈现**离散分布 (dispersed distribution)**。
  * 如果 $K(d) > \pi d^2$，点在尺度 $d$ 下呈现**聚集分布 (clustered distribution)**。
* **ArcGIS的 Ripley's K 函数**：
  * ArcGIS 使用了修正后的 $L(d)$ 来衡量观测模式与 CSR 预期模式之间的差异：$L(d) = \sqrt{\frac{A\sum_i\sum_j k_{i,j}}{\pi n(n-1)}}$
* **统计检验 (Statistic Testing)**：
  * 使用 **Monte-Carlo 方法** 对 $K$ 或 $L$ 函数进行统计检验。这是一种通过设定随机过程反复生成随机序列，并计算参数估计量和统计量的方法。
  * 在研究区内，利用蒙特卡洛方法产生 $n$ 次的完全空间随机分布点模式，通过最大值和最小值构建置信区间（Confidence Envelope）。
  * 如果观测值大于期望值（甚至超出上限值），则表示具有统计显著的聚类；如果小于期望值（低于下限值），则表示具有统计显著的离散。它衡量了一定距离范围内的空间聚集/分散程度。
* **【优点与局限性】**：
  * **优点**：
    1. 能够同时考虑多个空间尺度，揭示点模式的多尺度特征。
    2. 对数据的空间分布特征提供定量化的描述。
  * **局限性**：
    1. 对边界效应敏感，需要校正（如 Ripley's edge correction）。
    2. 计算复杂度较高，尤其是对于大规模数据集。

## 四、 空间模式分析的其他方法

除了上述提到的五种点模式分析方法，课件还引申了以下分析模式方法：
* **线模式 (Line patterns)**：例如线密度 (line density)。
* **基于像素或面积/多边形/三角形的模式 (Pixel-based or area/polygon/triangle patterns)**：例如泰森多边形 (Thiessen polygon)。
* **时空模式 (Spatio-temporal patterns)**。
* **自相关指数 (Autocorrelation index)**。
