# 空间分析课程复习笔记 - 第8讲 空间聚类分析

本笔记基于《Lect. 8 Spatial Clustering Analysis 2026.pdf》课件整理，严格遵循课件的语言表述。

## 一、 聚类分析简介 (What is Clustering Analysis?)

* **聚类 (Cluster)**：数据对象/特征/点的集合。同一个簇内的对象彼此相似，而不同簇中的对象彼此不相似。
* **聚类分析 (Clustering analysis or Clustering)**：根据数据中发现的特征发现数据之间的相似性，并将相似的数据对象分组为簇。
* **聚类分析的两种典型应用类型**：
    1.  作为一种独立工具 (stand-alone tool)，以深入了解数据分布。
    2.  作为其他算法的预处理步骤 (preprocessing step)。
* **聚类分析的丰富应用与多学科努力**：
    * 模式识别 (Pattern Recognition)。
    * 空间数据分析 (Spatial Data Analysis)：通过对特征空间进行聚类在 GIS 中创建专题图；检测空间聚类或用于其他空间挖掘任务。
    * 图像处理 (Image Processing)：例如在地球观测数据库中识别相似土地利用区域。
    * 经济科学 (Economic Science)：特别是市场研究。
    * 万维网 (WWW)：文档分类；对网络日志数据进行聚类以发现相似的访问模式。

## 二、 如何测量聚类的相似性 (How to Measure the Similarity of Clustering)

* **什么是好的聚类方法？**
    * 一个好的聚类方法将产生高质量的簇，具有：**高类内相似度 (high intra-class similarity)** 和 **低类间相似度 (low inter-class similarity)**。
    * 聚类结果的质量取决于方法使用的**相似性度量 (similarity measure)** 及其实现。
    * 聚类方法的质量还可以通过其发现部分或全部隐藏模式的能力来衡量。
* 测量聚类相似性/相异性的方法主要分为两类：基于距离的方法和基于相似系数的方法。

### 1. 基于距离的方法 (Distance-based method)

* 相似性通过**距离函数 (distance function)** 表达，通常是度量：$d(i, j)$。
* 对于区间尺度 (interval-scaled)、布尔值、分类、序数、比率和向量变量，距离函数的定义通常非常不同。
* 权重应根据应用和数据语义与不同的变量相关联。
* 很难定义“足够相似”或“足够好”。答案通常具有高度的主观性。
* 测量组间(不)相似性的一些流行距离：
    * **闵可夫斯基距离 (Minkowski distance)**：
      $$ d(i, j) = \sqrt[q]{|x_{i1} - x_{j1}|^q + |x_{i2} - x_{j2}|^q + \dots + |x_{ip} - x_{jp}|^q} $$
      其中 $(x_{i1}, \dots, x_{ip})$ 和 $(x_{j1}, \dots, x_{jp})$ 是两个 p 维数据对象，$q$ 是正整数。
    * **曼哈顿距离 (Manhattan distance)**：($q = 1$; L1 距离，向量的 1-范数)
      * 又称城市街区距离 (city block distance)。
      $$ d(i, j) = |x_{i1} - x_{j1}| + |x_{i2} - x_{j2}| + \dots + |x_{ip} - x_{jp}| $$
    * **欧氏距离 (Euclidean distance)**：($q = 2$; L2 距离，向量的 2-范数)
      * 属性：$d(i,j) \ge 0$, $d(i,i) = 0$, $d(i,j) = d(j,i)$, $d(i,j) \le d(i,k) + d(k,j)$。
* **计算簇间距离的典型替代方案 (Typical Alternatives to Calculate the Distance between Clusters)**：
    * **最小距离 (Smallest distance)**：一个簇中元素与另一个簇中元素之间的最小距离。
    * **最大距离 (Largest distance)**：一个簇中元素与另一个簇中元素之间的最大距离。
    * **平均距离 (Average distance)**：一个簇中元素与另一个簇中元素之间的平均距离。
    * **质心距离 (Centroid distance)**：两簇质心之间的距离。质心是簇的“中间(middle)”。
    * **中心点距离 (Medoid distance)**：两簇中心点之间的距离。中心点 (Medoid) 是簇中选定的、位于中心位置的对象。

### 2. 基于相似系数的方法 (Similarity-Coefficient-Based Method)

* 夹角余弦 (Angle cosine) 和相关系数 $r$ 是两类常用的相似系数。
* **夹角余弦 (Angle Cosine)**：假设对象和变量的数量分别为 $m$ 和 $n$。
    $$ \cos\theta_{ij} = \frac{\sum_{k=1}^{n} x_{ik} x_{jk}}{\sqrt{\sum_{k=1}^{n} x_{ik}^2 \cdot \sum_{k=1}^{n} x_{jk}^2}} $$
    其中 $i$ 和 $j$ 是两个对象的序数，$x_k$ 代表第 $k$ 个变量。
    * $\cos\theta_{ij} \in [-1, 1]$。夹角余弦值越大，对象越相似。

## 三、 空间聚类方法 (Spatial Clustering Approaches)

聚类方法包括划分方法、层次方法、基于密度的方法、基于约束的方法等。
课件介绍了 6 种主要类型，其中前 4 种进行了详细讲解：
1. **划分方法 (Partitioning approach)**：构建各种分区，然后通过某个准则（例如，最小化平方误差和）对其进行评估。典型方法：k-means, k-medoids, ISODATA, CLARANS。
2. **层次方法 (Hierarchical approach)**：使用某个准则创建数据（或对象）集的层次分解。典型方法：AGNES, DIANA, BIRCH, ROCK, CAMELEON。
3. **基于密度的方法 (Density-based approach)**：基于密度函数。典型方法：DBSCAN, OPTICS, HDBSCAN。
4. **基于约束的方法 (Constraint-based Approach)**：通过考虑用户指定或应用程序特定的约束来聚类对象。典型方法：Spatially Constrained Clustering, COD (障碍物)。
5. **基于模型的方法 (Model-based Approach)**：为每个簇假设一个模型，并尝试找到每个模型对彼此的最佳拟合。典型方法：SOM, EM, COBWEB。
6. **基于栅格或基于矢量的方法 (Raster-based or vector-based Approach)**。

### 1. 划分聚类 (Partitioning Clustering)

* 将 $n$ 个对象的数据库 $D$ 划分为 $k$ 个簇的集合，使得平方距离和最小化。给定一个 $k$，找到一个能优化所选划分准则的 $k$ 个簇的分区。
    * 全局最优：穷举所有分区。
    * 启发式方法：**k-means** 和 **k-medoids** 算法。
* **K-Means 聚类方法**：
    * 每个簇由簇的中心表示。包含 4 个步骤：1. 任意选择 $k$ 个对象作为初始 $k$ 个簇中心；2. 将每个对象分配给最相似的中心；3. 更新当前分区的簇质心（即簇的均值点）；4. 返回步骤2，直到不再有新的分配时停止。
    * **优点**：相对高效。时间复杂度为 $O(tkn)$，其中 $n$ 是对象数，$k$ 是簇数，$t$ 是迭代次数。通常 $k, t \ll n$。
    * **注释**：通常在局部最优处终止。
    * **缺点**：无法处理噪声数据和异常值 (outliers)；仅在定义了均值时适用，那么分类数据怎么办？需要预先指定簇数 $k$；不适合发现非凸形状 (non-convex shapes) 的簇。
* **K-Medoids 聚类方法**：
    * $k$-means 算法对异常值很敏感，因为具有极大值的对象可能会大大扭曲数据的分布。
    * 不使用簇中对象的均值作为参考点，而是使用**中心点 (medoid)**，即簇中最靠近中心位置的对象。
* **ISODATA 算法 (迭代自组织数据分析技术算法)**：
    * 基于 K-Means 算法，在聚类结果中加入了“合并 (merging)”和“分裂 (splitting)”两个操作，并设置算法运行控制参数。
    * **合并操作**：当两个特定簇（中心/类别）之间的距离小于给定阈值时，合并为一个；某簇的样本数超过给定阈值，该簇与其相邻簇合并。
    * **分裂操作**：当某簇的标准差大于给定阈值，或其样本数超过给定阈值时，该簇分为两个。

### 2. 层次聚类 (Hierarchical Clustering)

* 使用距离矩阵作为聚类标准。该方法**不需要**输入簇数 $k$，但需要一个终止条件。两种方法均可聚类对象和变量。
* **AGNES (AGglomerative NESting, 聚合层次分类)**：
    * **自下而上 (Bottom-up)**。
    * 在统计分析包中实现（如 SPSS, Splus）。
    * **处理过程**：1) 将每个对象/节点视为一个簇；2) 使用最小距离法和相异度矩阵合并相异度最小的节点；3) 以非降序方式继续；4) 最终所有节点属于同一个簇。
    * **树状图 (Dendrogram)**：将数据对象分解为几个级别的嵌套分区（簇树）。在所需层级切割树状图即可获得聚类，每个连通分量形成一个簇。
    * **Modified AGNES (修正的AGNES)**：第 3 步在计算新簇与其他节点的相异距离时，可以使用“最小距离 ($d_{rk} = \min\{d_{rp}, d_{rq}\}$) ” 或 “最大距离 ($d_{rk} = \max\{d_{rp}, d_{rq}\}$)”。这两种距离测量会导致结果的不同。
* **DIANA (DIvisive ANAlysis, 分裂层次分类)**：
    * **自上而下 (Top-down)**。
    * AGNES 的逆过程。最终每个节点形成自己的簇。

### 3. 基于密度的聚类 (Density-based Clustering)

* 基于空间分布，在周围噪声中寻找点特征簇。也可纳入时间以寻找时空簇。
* 工具通过检测点集中的区域以及被空或稀疏区域分隔的区域来工作。不属于簇的点被标记为**噪声 (noise)**。
* 使用**无监督机器学习**聚类算法。这些算法纯粹根据空间位置和到指定数量邻居的距离自动检测模式。称为无监督是因为它们不需要对“什么是簇”进行任何训练。
* **潜在应用**：寻找城市供水管网破裂的聚集以采取先发制人的行动；对恐怖袭击后的推文进行地理定位以指导救援；发现虫媒疾病家庭的最大聚集区以进行灭治。
* **三种方法**：
    1. **定义的距离 (DBSCAN)**：使用指定的距离将密集簇与稀疏噪声分开。最快的聚类方法，但只有在有非常明确的距离能很好地定义所有簇时才合适。产生具有相似密度的簇。允许使用时间字段和搜索时间间隔。
    2. **自适应 (HDBSCAN)**：分层密度的空间聚类。使用变化的距离将不同密度的簇与稀疏噪声分开。受数据驱动程度最高，所需用户输入最少。
    3. **多尺度 (OPTICS)**：使用邻居之间的距离和可达性图 (reachability plot) 将不同密度的簇与噪声分开。在微调检测到的簇方面提供最大的灵活性，但计算强度大。
* **DBSCAN 的部分概念**：
    * **e-邻域 (eps)**：空间中任何点的 e-邻域是包含在以该点为圆心、eps为半径的圆内的区域。
    * **点密度 (Point Density)**：e-邻域内包含的点数与邻域面积之比。包含的点数可视为点密度。
    * **核心点 (Core-point)**：如果一个点在其 eps 内的点数大于阈值 (**MinPts**)，则称为核心点。
    * **K阶邻居距离 (Kth-order neighbor distance)**：点与其第 $k$ 个相邻点之间的距离。K-Dis图是点距离排序示意图，用于确定 eps。
* **DBSCAN 中参数的作用**：
    * **每个聚类的最小要素数 (Minimum Features per Cluster / MinPts)**：决定了将一组点视为簇所需的最小特征数。设得越小，会检测出越多、越小的簇；设得越大，检测出的簇越少。它在计算**核心距离 (core-distance)** 时也很重要（从一点移动到所需的最小特征数所需的距离）。最小要素数越大，核心距离越大。
    * **搜索距离 (Search Distance / eps)**：如果在一个点的搜索距离内找到了“最小要素数”，该点被标记为核心点。**边界点 (border-point)** 在核心点的搜索距离内，但其自身的搜索距离内没有最小要素数。既不是核心点也不是边界点的标记为噪声。

### 4. 空间约束多元聚类 (Spatially Constrained Multivariate Clustering)

* 根据一组要素属性值和可选的簇大小限制，寻找**空间连续 (spatially contiguous)** 的要素簇。
* 使用无监督机器学习方法。给定要创建的簇的数量，它将寻找一个解，使得每个簇内的所有要素**尽可能相似**，而各个簇本身**尽可能不同**。
* 要素相似性基于 **分析字段 (Analysis Fields)** 中指定的属性。
* 算法采用**连通图 (connectivity graph / minimum spanning tree，最小生成树)** 和 SKATER 方法寻找自然聚类，以及证据积累来评估聚类成员似然性。
* **空间约束 (Spatial Constraints)** 确保生成的簇在空间上是**近接的 (proximal)**。
    * **仅邻接边 (Contiguity edges only)**：共享边的多边形。
    * **邻接边和角 (Contiguity edges corners)**：共享边或顶点的多边形。多边形默认值。
    * *(注：如果不连续多边形或完全没有相邻多边形，不宜使用多边形邻接选项)*
    * **修剪的德劳内三角网 (Trimmed Delaunay triangulation)**：确保同簇要素至少有一个共同的自然邻居。概念上从要素质心创建不重叠的三角网。点要素默认值。
    * **从文件获取空间权重 (Get spatial weights from file)**：指定 .swm 文件。
