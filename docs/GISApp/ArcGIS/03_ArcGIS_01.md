# ArcGIS 的产品

---


ArcGIS 不仅仅是一个软件，而是一个涵盖了桌面、服务器、云端、移动和开发的完整 Web GIS 生态系统，主要有下面3种。下一章将说明关于如何调教arcGIS pro 3.3


## 1. 桌面端

arcGIS 最核心的工作环境，经历了从 32 位到 64 位架构的彻底转型。

| 阶段 | 代表产品 | 核心特征 | 现状 |
| :--- | :--- | :--- | :--- |
| **早期** | **ArcView 3.x** | 奠定了 Shapefile 格式标准，仅支持基础制图。 | 历史的遗迹 |
| **经典** | **ArcMap** (ArcGIS Desktop) | 包含 ArcMap, ArcCatalog 等；32 位架构，功能极度成熟。 | 停留在维护阶段，不再更新功能。 |
| **现代** | **ArcGIS Pro** | 64 位、多线程；Ribbon 界面；2D/3D 一体化；深度集成 Python。 | 主流 |



## 2. 企业级 arcGIS

从单一的 **ArcGIS Server** 演进为 **ArcGIS Enterprise**

* **包含四个核心架构**：
    1.  **ArcGIS Server**：将地图发布为 Web 服务（URL）。
    2.  **Portal for ArcGIS**：企业内部的“地图门户”，类似于私有版 ArcGIS Online。
    3.  **ArcGIS Data Store**：存储托管要素和空间大数据的数据库。
    4.  **ArcGIS Web Adaptor**：负责与现有 Web 服务器（如 IIS/Tomcat）整合及负载均衡。



## 3. 在线云 GIS (Cloud GIS)

* **ArcGIS Online (AGOL)**：与 Pro 无缝互通，可一键将桌面端成果“发布到云端”。
