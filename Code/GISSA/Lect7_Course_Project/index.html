    空间分析课程复习笔记 - 第7讲 课程项目与案例学习¶

    本笔记基于《Lect.7 Course Project 2026.pdf》课件整理。本讲主要介绍课程项目的相关要求，并展示了多个优秀的空间分析应用案例和数据获取途径。

    一、 案例学习指南 (Examples & PPDAC)¶

    在进行项目设计和案例学习时，应带着以下问题（基于PPDAC模型思想）进行思考：

    1. Problem (问题)：案例主要解决什么科学或实际问题？
    2. Plan (计划)：案例的技术路线是怎样的？用到了哪些核心研究方法？
    3. Data (数据)：案例用到了哪些数据？这些数据是如何获取的（数据源）？
    4. Analysis (分析)：分析过程如何？结果如何？结论是否可信？
    5. Conclusions (结论与反思)：案例在研究方法、数据处理、成果表达等方面有哪些可以借鉴的亮点和需要改进的地方？

    优秀案例列举¶

    1. 易智瑞GIS开发竞赛优秀作品¶

    • 遥感应用组：基于高光谱数据的矿化信息提取；基于ENVI深度学习的多源SAR影像水淹区域提取；基于机器学习的城市群PM2.5时空变化及归因研究等。
    • 地理设计组：气候变化下的农作物物候响应机制；基于XGBoost的城市热岛预测及人口暴露分析；基于多层网络的即时配送生活圈时空动态模式挖掘；基于深度学习的城市公园游客情感时空分异特征研究等。

    2. 学术论文案例 (Paper Examples)¶

    • 生态环境时空演变：《成渝双城经济圈生态环境质量时空演变格局及其驱动力》。利用Landsat影像构建遥感生态指数(RSEI)，结合Sen-MK趋势分析和最优参数地理探测器模型(OPGD)评估生态质量并分析其空间异质性及驱动力。
    • 城市空间可及性与公平性：《东京都市圈可持续餐饮选择可及性的差异》(Nature Cities)。利用海量餐厅和菜单数据，构建多维度的“可持续外出就餐指数(SDOI)”，揭示公共交通导向型发展(TOD)如何影响餐饮格局，并指出空间分布的不平等性。
    • 城市防洪韧性评估：《基于GIS的巴基斯坦白沙瓦市城市防洪韧性评估》。采用层次分析法(AHP)确定权重，结合洪水危险性、暴露度、敏感性和应对能力等指标计算城市防洪韧性指数(UFRI)，生成韧性地图并使用ROC曲线进行验证。
    • 社交媒体与人类行为：《利用社交媒体平台数据了解游客在旅行前、中、后的旅行行为》。
    • 其他案例涵盖了点模式、线模式、区域模式在交通事故、土地覆盖变化、能源效率等领域的广泛应用。

    二、 海报、PPT及答辩要求 (Poster, PPT & Presentation)¶

    期末课程项目汇报的PPT与海报应包含以下核心板块：

    1. 项目背景与意义
    2. 研究方法与技术路线
    3. 研究区、数据（及预处理）
    4. 研究结果与分析
    5. 总结（与展望）
    6. 组员贡献

    答辩时间与形式要求：

    • 时间安排：每组答辩总时间为 10分钟（其中陈述时间8分钟，问答时间2分钟）。
    • 答辩日期：在期末考试前后7天内进行，具体时间另行通知。

    三、 空间数据获取途径 (Data Sources)¶

    课件汇总了进行空间分析常用的各类数据库与平台：

    1. 遥感与再分析数据¶

    • 计算与获取平台：Google Earth Engine (GEE)、地理空间数据云 (gscloud.cn)、EarthExplorer (USGS)、PieEngine (航天宏图)、欧空局 Sentinel 数据平台。
    • 科学数据中心：资源环境科学与数据中心 (resdc.cn)、国家对地观测科学数据中心 (chinageoss.cn)、国家地球系统科学数据中心 (geodata.cn)、全球变化科学研究数据出版系统、国家生态系统观测研究网络等。
    • 示例数据：全球500米分辨率“类NPP-VIIRS”夜间灯光数据集等。

    2. GIS与众源数据 (Crowdsourced Data)¶

    • 基础地理数据：OpenStreetMap (OSM) 矢量数据、GADM全球行政区划边界数据。
    • POI与轨迹数据：百度地图数据、高德地图数据、ArcGIS Online。
    • 专业/专题数据：ACLED武装冲突与事件数据、EM-DAT全球自然灾害数据库、WorldPop全球高分辨率人口密度数据。

    3. 统计年鉴数据¶

    • 城市与农村：《中国城市统计年鉴》（人口、GDP、水资源、绿地等）、《中国城市建设统计年鉴》（公用设施水平等）、《中国农村统计年鉴》（农作物面积、受灾情况、化肥农药使用等）。
    • 经济与行业：《中国投资领域统计年鉴》、《中国房地产统计年鉴》、《中国零售和餐饮连锁企业统计年鉴》、《中国文物文化和旅游统计年鉴》。
    • 国际数据：世界银行数据 (World Bank)、联合国世界自然与文化遗产保护区数据等。
